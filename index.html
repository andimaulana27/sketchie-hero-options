The science

We optimized for whether they remember it tomorrow.

Fast and cheap only matter if the video is genuinely good. The generator enforces rules drawn from peer-reviewed research.

12-30sScene length

One idea per scene.

3-7Elements

Counted at the end of the scene.

2-5sReveal spacing

Never two closer than 1.2 seconds.

500msWord sync

Each element lands on its word.

140-160Words per minute

Spoken register, not read.

3 wordsLabel limit

A keyword, never a sentence.

Question

Every video closes by asking the viewer to produce the answer.

Pause

The video holds, so the answer is theirs before it is given.

One line recap

Then the loop closes. The question is never replaced by a summary.

The six minute ceiling comes from research across 6.9 million learning sessions. A deliberate cap, not a technical limit. Read the full spec with citations.

The honest FAQ.

including the one we lose

01Can I edit a single scene?
Yes. Scenes are addressable, so an edit targets one of them, that scene re-renders alone, and the rest keep their timing, narration, and artwork.
02What if the source is too long?
Longer material becomes a chaptered series. Individual videos move in 30-second steps up to six minutes, or Sketchie picks the length.
03How does a video end?
With a retrieval beat: a question, a pause, then a one-line recap. The pause is deliberate.
04Can I try it without paying?
Free access is two watermarked Icons videos, up to one minute each, with no card required.
05Is Sketchie faster than Simi?
No, and we say so. Simi is faster at first generation. The argument is time to a video you will publish, revisions included.
06Can developers drive it?
An API returns the video and its scene graph, with an MCP server for agents and a CLI. Solo is app-only. API and MCP access starts on Plus and is included in Pro, subject to Credit charging verification. API and MCP usage is 2x the equivalent in-app Credit quote, subject to approval and billing verification.
