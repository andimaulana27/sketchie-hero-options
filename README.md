# Sketchie Hero Directions

Interactive Sketchie landing hero concept with four directions:

- A: Composer-first
- B: Persistent workspace
- C: Guided brief
- D: Example-first

All simulations are illustrative and run locally in the browser. This artifact does not perform generation, upload files, create accounts, or call a runtime API.

To view it locally, open `index.html` in a browser.

GitHub Pages preview, available after publishing: [https://andimaulana27.github.io/sketchie-hero-options/](https://andimaulana27.github.io/sketchie-hero-options/)
